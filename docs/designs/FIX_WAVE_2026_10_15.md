### PR 1a と PR 1b — 復旧(重大度: 高。最初に出荷)

PR 1a は項目 1、5、6、7、11 を含みます。PR 1b は項目 2、3、4、12、13、16、W を含みます(項目 13 と 16 は `setup` の担当を1つにするため、こちらに移します)。

**1. Claude Code 2.1.300 の自動圧縮の後で /autoplan がロックする。#3196 を採用(#3194 を修正)。** 圧縮の後、`preservedSegment` の境界が親子の循環を作り、フェーズガードはすべてのフェーズの開始を `close_incomplete` で拒否し、実行を続けられなくなります。#3196(vilano93)は `lib/claude-journal-records.ts` に境界の扱いを教えます。検証済み: `test/autoplan-compaction-preserved-segment.test.ts` は main では 7件中 2件が失敗し、PR では通ります。CI は緑です。2回の圧縮を経ても問題ありません。追加事項: ウォーク後にルートから到達できない所有ノードがあり、かつ `compact_boundary` のレコード(その論理的な親、または保持リスト)がその到達不能な部分を説明できる場合、それをガードの既存の `unrecognized_shape` の処分(目に見える警告と決定ログの行を伴う許可)に対応させます。誤った `close_incomplete` は出しません。孤立した、またはまだフラッシュされていないコンポーネントは、今の動作を維持します。こうすることで、フェイルオープンの範囲が圧縮以外に広がることはありません。これは PR のゲート整合性の編集として記載します。ネガティブコントロール: 既存の拒否テストと、取得済みのフィクスチャ(`autoplan-publication-guard`、`-hook`、`guard-reasons`、`autoplan-publication-boundary-361c.json`)は、今でも拒否すること。レビュー担当者のテスト: 約5万レコードの履歴と3回の圧縮を持つジャーナルが、フックの時間予算内で終わること(必要なら、ウォークごとに `descends` をメモ化する)。

**2. 衝突する autostash が、稼働中のインストールに衝突マーカーを残す。#3189 と #3191 を、1つの共有 bin を通して採用。** git 2.55 では、衝突する stash を伴う `merge --ff-only --autostash` が終了コード 0 で終わり、インストールの追跡ファイルにマーカーを残し、その上で setup が走ります。#3189(BenjaminDSmithy)は未マージのファイルを検出し、チェックアウトされたリビジョンを復元し、stash を保持します。検証済み: そのテストの 10件中 8件が main で失敗します。コミット `069b80b` と `8dc0078` を採用し、`3d1caac` は捨てます。
- 早送りと復旧は、新しい bash の bin `bin/gstack-ff-update <dir> <rev>` に移します。これは、インストールのツリーを動かす唯一のコードです。`bin/gstack-session-update`、`/gstack-upgrade` のステップ 4、そして保留されたインストールの復旧コマンド(項目 3)から呼ばれます。ステップ 4 は、復旧を散文の中で再実装することはありません。

## レビューからの修正(改訂版3のレビュー。すべてのレーンを拘束)

改訂版3(スナップショット `5d243037`)は、同じ6人の視点でレビューされました。23件の指摘(CEO 6+3、DX 6+1、Eng 5+2)があり、重大(High)なものが1件、重大なものはなく、ユーザーへの確認事項もありませんでした。改訂版2の指摘はすべて解決済みと確認されました。どれもスコープや方向性は変えないため、もう1回レビューするのではなく、レーンの作業として適用します。

1. **救済の書き出しは、上流の修正を巻き戻してはならない(DX ネイティブ F1、高。DX 外部 F1)。** 救済コミットの親は、更新前の HEAD(その本来の基準)です。バナーは `git -C '<dir>' diff <ref>^ <ref> > ~/gstack-local-edits.patch`(ユーザーの差分だけ)を表示し、捨てたパッチを、使い捨てのチェックアウトで `git apply -3` することを示唆します。すでに未マージのキャプチャは「手動での解決が必要」と表示します。テスト: パッチが触るのはユーザーが編集したパスだけであること。ユーザーの編集を復元しても、無関係な上流の修正が残ること。
